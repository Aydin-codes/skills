# skills

This repository hosts some of my personal favorite skills that I have created for coding agents like Claude Code, Codex, Cursor, and more.

## Skills

| Skill | What it does | Link |
| --- | --- | --- |
| toolkit | Gives your agent a free-first map of stacks, assets, libraries and example repos, plus checks to run before calling work done | [toolkit/](toolkit/) |
| design-studio | Designs like a real designer: interviews you, shows real options to pick from, then builds only what's needed | [AydinHeugh/design-studio](https://github.com/AydinHeugh/design-studio) |
| vert-research | Interviews an athlete and builds a vertical-jump training plan from graded sports-science research | coming soon (private repository as for now) |

## Install

These use the open Agent Skills format (SKILL.md), so they work in tools that support it.

- **Claude app:** download the skill's folder, zip it, then Settings → Capabilities → Skills → Upload skill.
- **Claude Code:** put it at `~/.claude/skills/<skill-name>/SKILL.md`
- **Codex:** put it at `~/.agents/skills/<skill-name>/SKILL.md`
- **Other tools:** put the folder in your tool's skills folder (check its docs).

## Example

Use the toolkit to plan a 3D lesson page about how a power grid works.
